## 🚀 How to Use

### **Option 1: View Online**
1. Navigate to the GitHub repository
2. Click on any `.html` file
3. Click the "Raw" button to view the code
4. Use a web browser to open the files

### **Option 2: Deploy to GitHub Pages**
1. Go to repository Settings
2. Scroll to "GitHub Pages"
3. Select "main" branch as source
4. Your site will be live at `https://username.github.io/pradeep-lakhmani-fabric`

### **Option 3: Local Development**
1. Clone the repository
2. Open `index.html` in your web browser
3. Use any text editor to modify files
